# Currículo Mobile

Aplicativo mobile desenvolvido com React Native + Expo para gerenciamento e visualização de currículos e portfólios profissionais.

## Funcionalidades

* Listagem de currículos cadastrados
* Visualização detalhada do perfil
* CRUD completo de:

  * Habilidades
  * Experiências acadêmicas
  * Experiências profissionais
  * Projetos
* Compartilhamento do currículo em formato Markdown
* Integração com API REST em produção
* Navegação utilizando Expo Router
* Interface moderna utilizando React Native Paper

## Tecnologias Utilizadas

### Front-end

* React Native
* Expo
* Expo Router
* TypeScript
* React Native Paper
* Expo Sharing
* Expo File System

### Back-end

* Node.js
* Express
* Sequelize
* PostgreSQL
* NeonDB
* Vercel
